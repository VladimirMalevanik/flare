## Implemented contracts

- All new acquisition/signup snapshot, funnel fact, voluntary interaction and reconciliation collection is off by default. Signup checks policy before inserting its optional snapshot; facts require an enabled policy and positive fact retention; inspection returns before collecting, and the event privacy guard also rejects narrow interaction inserts while disabled. Missing/disabled policy creates no measurement records. Auth, actual verification, capture/import/Analyze domain outcomes and unrelated authenticated events retain their behavior. Explicit withdrawal and retention cleanup can still keep minimal suppression tombstones and remove existing data while collection is off. Anonymous collection is touch-only and explicit opt-in. No production policy values are seeded. The private singleton policy requires notice/revision, eligibility, cleanup owner, lookback/cookie/raw/link/fact lifetimes, admission/storage/deadline limits, reporting calendar/window and cohort disclosure threshold. Campaign/ref/domain values require operator allowlists. A ref is an attribution label, never a reward or entitlement.
- Browser public-route navigation sends only bounded normalized fields after policy and session opt-in checks. It discards conflicting duplicates, double/ambiguous encoding, excessive fields and private routes. The backend rejects duplicate JSON keys, enforces a 1024-byte body and stream deadline, uses socket peer pseudonyms rather than forwarded claims, process admission and a database global try-lock, persistent global/network/reference/storage caps, and a query deadline. Churning cookies cannot reset global budgets. Cookie references are server-issued opaque UUIDs stored only as hashes; existing unknown/expired/consumed references cannot recreate visitor state.
- First observed touch and last eligible non-direct touch are stored separately; direct touches do not erase campaigns. Signup consumes the reference and freezes snapshots inside a bounded optional savepoint in the auth transaction. Account and verification truth come directly from auth_users; there is no auxiliary signup/verification trigger. A locked/failing snapshot sink cannot roll back signup. Missing snapshots remain explicit coverage gaps and later login/touch cannot rebuild them. The hook preserves a shorter preexisting statement_timeout and restores it on success/failure. Login never rewrites attribution. Auth/logout clears acquisition cookies; client auth transitions clear opt-in session state. SMTP failure still leaves one durable account. Actual consumed-token verification, bypass and legacy unknown are distinct.
- Compact domain hooks record committed manual capture, completed synchronous imports and canonical ZIP publication with logical ID, actor/workspace, time and bounded counts. Import observations use an isolated exception block, NOWAIT table locking and a bounded restored lock timeout; analytics consumers cannot become prerequisites for publication. Capture marking is confined to the explicit ItemService publication path. ZIP staging/per-entry writes are excluded. Facts roll back with domain work and survive activity-event loss. Reconciliation projects missing canonical package and completed synchronous-import IDs from retained authoritative domain rows, so a lower sequence committed later is not lost. Reconciliation returns zero while collection is disabled. Once an approved policy is enabled, bounded reconciliation may project retained authoritative imports from before enablement only within the configured fact retention window; it never reconstructs missing signup snapshots or unobserved capture/inspection actions. This historical import coverage is labeled in every report. Run bounded reconciliation to exhaustion before producing a report; the report explicitly describes this freshness condition. Capture/Analyze facts remain small transactional observations; their regular domain success survives loss of best-effort activity events.
- Analyze facts require successful terminal analysis AND matching Flare generation, including zero-result completion. Logical run, actor, mode, time and counts survive job/cycle cleanup. Unknown legacy mode remains unknown. No provider, retrieval, publication gate or daily Analyze allowance changes.
- Voluntary Flare/evidence inspection uses a separate narrow authenticated endpoint, actor/tenant/target/lineage validation and interaction-ID retry dedupe. Card clicks and source links emit it. Hydration, deep links, revision refresh, GETs and polling do not. The old general event endpoint cannot create funnel completion facts.
- Reporting is a private aggregate SQL capability; app/worker have neither raw growth-table access nor report execution. A separately provisioned `flare_growth_reporter` receives only function execution. Account and workspace-creator units, first/last basis, UTC-v1 calendar, window, coverage, unknown verification/attribution, ordering, later-day opportunity, freshness and non-causal limitations are explicit. No headline activation/D7/W1 rate is selected. Bounded attribution buckets actually select frozen first/last fields: source, medium, campaign, ref, external domain and canonical route, each with the same ordered deduped milestones. Currently approved vocabulary is exportable; retired labels become other. Direct-or-unknown, unlinked and missing-snapshot coverage are distinct. The entire breakdown is suppressed if any bucket fails the cohort threshold or there are more than 100 buckets; JSON aggregation examines at most 101 buckets. CSV exports include only fixed numeric aggregates and these bounded approved dimensions, with spreadsheet formula escaping. Durable accounts, including SMTP failure and snapshot outages, remain in the denominator with snapshot_present/snapshot_missing coverage.
- Human-return-v1 qualifies only explicit foreground Flare/evidence inspection on a later UTC day after ordered inspection. Capture/import/Analyze completion times are asynchronous and never establish return, even for manually requested work. Scheduled completion and logical retries remain excluded. This narrow qualifying-action coverage is labeled in every report. Signup, inspection and window date casts explicitly use UTC-v1 and do not depend on session timezone or change the workspace-local Analyze quota.

Account deletion cascades growth identity/facts and deletes actor activity; workspace deletion cascades growth data when domain deletion succeeds. Cleanup uses bounded batches and explicit policy durations. Old facts outside retention cannot be reintroduced by reconciliation. Anonymous forget removes its raw visitor row; expiry independently removes it if delivery fails. No stored exports or rollups need separate invalidation.
