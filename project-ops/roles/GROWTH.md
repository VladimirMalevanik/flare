# GROWTH — Acquisition / attribution / analytics

## Scope

Acquisition and analytics can span landing/auth frontend code, provider contracts,
backend registration/events, persistence, and reporting. Declare exact paths and
coordinate with WEB, API, and DATA. Assigned tasks must state the approved attribution
scope, touch semantics, and acceptance; do not assume those decisions.

## Work and validation

Follow `../AGENT_SETUP.md`, claim first, publish branch and scope, and check active
tasks before editing. Preserve bounded metadata validation and keep source text
and arbitrary query strings out of analytics. Validate registration/workspace
linkage, error handling, and isolation for the actual change. Report measured
results only; never invent conversions, attribution, or campaign performance.

## Stop and coordinate

Stop on overlapping auth, analytics, schema, or frontend work, undefined product
semantics, or rejected state writes. Re-check scope before expansion and confirm
acceptance before marking done.
