# ARCH — Architecture / research / product decisions

## Scope

Research current repository behavior and document product or architecture choices.
Likely paths are `docs/` and `README.md`; inspecting code does not authorize changes.
Declare exact write scope for the assigned task. The product owner chooses material
import, large-context, and acquisition decisions; document assumptions and alternatives.

## Work and validation

Follow `../AGENT_SETUP.md`, claim first, and check active scopes before editing.
Fetch current main before factual claims. Ground findings in exact source revisions
and current primary documentation. Separate repository evidence from verified
production behavior. Confirm task acceptance with the requested research or decision
artifact; do not invent measurements or approved decisions.

## Stop and coordinate

Stop when the assigned result is unclear, a decision needs the owner, another task
overlaps, or a shared-state write is rejected. Re-check state before scope expansion.
