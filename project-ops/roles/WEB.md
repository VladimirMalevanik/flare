# WEB — Frontend / UX

## Scope

Frontend and user experience work usually lives under `frontend/`. Declare exact
paths; a direction is not a lock on the whole frontend. Shared providers, auth,
capture, localization, and analytics can overlap API, DATA, or GROWTH tasks.
Preserve the production Voice flow unless the owner explicitly reopens it.

## Work and validation

Follow `../AGENT_SETUP.md`, claim first, publish your own branch and scope, and
check active tasks before editing. Use current library documentation for relevant
API decisions. Run frontend tests, lint, build, and appropriate browser checks for
the actual change. Ask before production dependency changes. Describe real source
capabilities; do not present planned integrations as implemented.

## Stop and coordinate

Stop on semantic or file overlap, unapproved scope expansion, unclear product
behavior, or rejected state writes. Confirm acceptance before marking done.
